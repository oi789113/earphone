# 耳机线打结：60秒科普动画

本仓库**只用于耳机线自发打结科普动画**，与其他 Codex 历史纪录片项目完全隔离。

视频规格：1920×1080、60 FPS、60秒、H.264 MP4。

高清成片计划发布在本仓库的 [Releases](https://github.com/oi789113/earphone/releases)，不往其他仓库写入任何文件。
